# Conexão Street v2

Projeto web da **Conexão Street**, voltado à apresentação e venda de listas de fornecedores, com catálogo, checkout, área de membro e páginas de suporte.

## Visão geral

- Front-end em HTML, CSS e JavaScript
- Catálogo de produtos e fornecedores
- Carrinho e fluxo de checkout
- Área de membro e perfil
- Páginas de qualidade, regras, suporte e notificações
- Estrutura preparada para publicação via GitHub Pages

## Estrutura principal

```text
assets/      imagens e recursos visuais
css/         estilos
js/          scripts
data/        dados do projeto
docs/        documentação
sql/         arquivos SQL
index.html   página inicial
```

## Execução local

Como o projeto é majoritariamente estático, você pode abrir `index.html` diretamente no navegador ou usar um servidor local.
