## Convenção recomendada daqui para frente

Para manter a conta organizada:

- usar nomes de repositório em kebab-case quando possível;
- manter um README com objetivo, stack, execução e status;
- evitar subir chaves, tokens, senhas ou dados pessoais;
- usar `.env` para configurações locais e manter `.env` no `.gitignore`;
- usar branches para mudanças maiores;
- preferir mensagens de commit descritivas em vez de apenas “Add files via upload”;
- manter projetos de teste claramente identificados;
- arquivar projetos realmente encerrados apenas quando houver certeza de que não serão mais usados.
